# Sp1200kv62 # 

Экспериментальный Android-сэмплер, вдохновлённый классическими 12-битными сэмплерами.

Проект создаётся через телефон с использованием GitHub и GitHub Actions.

## Стек

- Kotlin
- Jetpack Compose
- C++
- Oboe

## План

- Milestone 1: 8 пэдов и низколатентный звук через Oboe
- Milestone 2: загрузка WAV-семплов
- Milestone 3: библиотека семплов
- Milestone 4: waveform editor
- Milestone 5: MIDI sync

## Сборка

Позже будет добавлен GitHub Actions workflow для сборки debug APK.
